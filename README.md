📘 AI-Based Digital Addiction & Mental Health Risk Predictor

📌 Overview
This project uses Machine Learning to predict digital addiction risk levels among youth based on behavioral patterns such as screen time, sleep duration, social media usage, and mood score.

🎯 Objective
To develop an AI model that identifies addiction risk levels (Low, Moderate, High) and helps in early awareness of potential mental health concerns.

🛠 Technologies Used
Python
Google Colab
Pandas
Scikit-learn
Matplotlib

🤖 Model
Algorithm: Random Forest Classifier
Train-Test Split: 80-20
Evaluation Metrics: Accuracy, Precision, Recall, Confusion Matrix

📊 Result
The model successfully predicts digital addiction risk levels with high accuracy and identifies important behavioral factors affecting mental health.
